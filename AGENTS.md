# AGENTS.md

**CLAUDE.md** is this repository's agent guide, and it applies to every agent, whatever the model or CLI. Read all of it before your first edit. It is the single source of truth for commands, the CI gate order, the process split, test seams, UI tokens, and the gotchas that fail silently.

**CONTEXT.md** is the domain glossary (Site, Agent, Session, Launch Target …). Use its terms in code, commits and PRs.

**Implementing a GitHub issue** labelled `ready-for-agent`: follow `docs/agents/implementing-a-ticket.md`.
